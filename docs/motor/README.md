# Motor de partidos — índice del diseño funcional

> [Índice general](../README.md) · [Normas](../../AGENTS.md) · [Estado](../estado.md)

**Aviso de estado.** Todo lo que sigue es **diseño funcional definido**, no implementación. «Definido», «implementado», «validado», «semilla provisional» y «calibrado» son estados distintos (ver [uso y estados](uso-y-estados.md)). Hoy no existe motor ni laboratorio: [estado](../estado.md).

## Tarjeta de principios deportivos

Orientación breve; el detalle está en cada enlace.

- **Primer hito:** un partido completo integrado y revisable desde el laboratorio ([identidad y alcance](alcance/c01-identidad-alcance-y-decisiones-de-direccion.md), [laboratorio](laboratorio/c24-modalidades-y-primer-laboratorio.md)). Un ejemplo aislado de bloqueo directo o una microacción **no** es el hito de validación inicial; los ejemplos del funcional se conservan como explicaciones o casos dentro del partido completo.
- **Motor, tácticas y atributos se conciben y construyen juntos** ([jugadores](jugadores/README.md), [tácticas](tacticas/README.md), [simulación](simulacion/README.md)).
- **Cálculo por acontecimientos relevantes dentro de posesiones, con contexto pequeño.** No se simulan movimientos de todos los jugadores a cada segundo o milésima ([flujo de partido](simulacion/c11-flujo-de-partido-posesiones-y-contexto-pequeno.md)).
- **Partido vivo y tácticamente rico, con ejecución interna sencilla y comprensible** (contrato de sencillez: [flujo de partido](simulacion/c11-flujo-de-partido-posesiones-y-contexto-pequeno.md#grupo-11-01)).
- **Efectos observables y explicables** de las decisiones tácticas y de las diferencias entre jugadores ([selección y desenlace](simulacion/c12-p01-seleccion-oportunidades-y-desenlaces.md), [análisis táctico](estadisticas/c21-p01-lectura-ofensiva-libro-y-direccion-de-juego.md)).
- **Un mismo núcleo deportivo para todos los modos de partido**; la presentación y el detalle del registro pueden variar como allí se define ([laboratorio](laboratorio/c24-modalidades-y-primer-laboratorio.md#grupo-24-04)).
- **Parámetros deportivos administrables en configuración versionada**, con los límites y mecanismos previstos; no constantes ocultas ([panel y perfiles](configuracion/c26-p01-panel-de-administracion-finalidad-y-organizacion.md)).
- **Estados de los datos conservados:** semillas provisionales, contenido por completar y parámetros calibrados no se confunden ([perfil inicial y semillas](configuracion/c29-p01-perfil-inicial-semillas-y-trabajo-numerico.md)).
- **El laboratorio es reutilizable por el futuro manager;** no se construye un motor desechable distinto ([laboratorio](laboratorio/c24-modalidades-y-primer-laboratorio.md)).
- **Las siguientes etapas se acuerdan por entregas;** la documentación no ordena implementar el catálogo completo ni iniciar el resto del manager ([alcance de construcción](alcance/c30-alcance-de-construccion-y-trabajos-por-completar.md)).
