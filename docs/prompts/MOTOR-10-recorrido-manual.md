# MOTOR-10 — recorrido manual para Dennis

Arranque: `npm run dev` → <http://localhost:5173/> (variable `PORT` para otro puerto). Pruebas: `npm test`; datos: `npm run data:check`; cinco partidos de integración (acta y análisis conciliados): `node scripts/integration-motor10.js`.

**Perfil**: base **`SEM-MOTOR01-20261016+…+SEM-MOTOR09-20261016+SEM-MOTOR10-20261016`** (efectivo; aparece en la insignia superior). **Semilla de referencia** `20261016`: da **83–103**, igual que en MOTOR-09 (MOTOR-10 solo lee el partido: no cambia el deporte, el acta ni el formato `export/8`).

Si tu navegador conserva un perfil anterior activo, entra en **Panel de ajustes › Inicio** y pulsa **«Activar la base de MOTOR-10»**: es explícito y no migra nada en silencio. Un perfil anterior sigue siendo jugable y reproducible; el análisis usa entonces los valores por defecto del código y lo indica («por defecto del código»).

**Qué es y qué no es todavía**: el análisis lee hechos y acta ya producidos. Los umbrales del resumen y de muestra son editoriales (SEM), no significación estadística; nada está calibrado. El mapa solo conoce la zona (aro, pintura, media, triple), no el lado. Escenarios de laboratorio: los casos preparados de MOTOR-09 (Partido › «Casos de laboratorio preparados») siguen rotulados como preparados y conservan sus originales.
